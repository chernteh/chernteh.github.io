Market-News Bot

Guarding an Unattended LLM Against Hallucination

A fully automated daily market brief delivered over Telegram. A two-model LLM pipeline (Qwen3.6 27B + GPT-OSS 120B) ranks the news and writes each summary, while Python guardrails block unsupported claims and a price check across up to four data sources verifies every price before it is sent.
